# 🧮 Calculadora em Python com Interface Gráfica

Este projeto consiste no desenvolvimento de uma calculadora utilizando **Python** com interface gráfica criada com **PySimpleGUI**.

## 🚀 Funcionalidades

* Operações básicas:

  * Soma (+)
  * Subtração (-)
  * Multiplicação (*)
  * Divisão (/)
  * Módulo (%)
* Interface gráfica interativa
* Tratamento de erros para entradas inválidas

## 🧠 Conceitos aplicados

Durante o desenvolvimento, foram aplicados conceitos importantes como:

* Separação entre lógica e interface (modularização)
* Importação entre arquivos Python
* Tratamento de exceções (`try/except`)
* Manipulação de eventos em interface gráfica

## 📁 Estrutura do projeto

```
Calculadora/
│
├── Calculadora.py   # Lógica das operações
├── Layout.py        # Interface gráfica (PySimpleGUI)
```

## ▶️ Como executar

1. Certifique-se de ter o Python instalado
2. Instale a biblioteca PySimpleGUI:

   ```
   pip install PySimpleGUI
   ```
3. Execute o arquivo:

   ```
   python Layout.py
   ```
